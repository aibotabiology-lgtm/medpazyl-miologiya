MedPazyl Миология — Vercel-ге жүктеуге дайын статикалық сайт.

Құрамы: index.html, img/logo.png, data/index.json, data/l01..l17.json, data/img/ (суреттер), vercel.json

Жүктеу:
  1) Архивті ашыңыз (index.html папканың түбінде тұруы керек).
  2) vercel.com → Add New → Project → GitHub-тағы папканы импорттаңыз,
     немесе осы папканың ішінде терминалда:  npx vercel --prod
  3) Framework Preset: Other; Build Command мен Output Directory бос.
